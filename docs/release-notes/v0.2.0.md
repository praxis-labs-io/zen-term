ZenTerm now updates itself.

## New

**Auto-update.** ZenTerm checks for new versions and installs them in place, so this is the last build you download by hand. When one is ready, an update card appears in the app, themed to match it, with the notes for what changed and a button to install and relaunch. You stay in control of when it happens.

## Install

Open the DMG and drag ZenTerm to Applications. From here on, updates arrive in the app. macOS 14 or later, Apple Silicon.

## Reporting a bug

Open an [issue](https://github.com/praxis-labs-io/zen-term/issues) with the version from the bottom of Settings (⌘,).
