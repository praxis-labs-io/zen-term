## New

**A drawer, Scratch or a tool float can ask for you.** Only a background tab posted a card when an agent needed an answer. Now anything out of sight does. The card carries the tab's title and names the drawer or tool it came from, and Switch opens it. Looking at a surface answers its card, so visiting a tab clears what that tab puts on screen and a collapsed drawer goes on asking.

**The toolbar dot's color says what it wants.** A drawer or tool float's dot takes the theme's attention color while an agent there is waiting on you, and its positive color when a long command there finished unseen. Otherwise it is the accent, as before. Those are the same colors a tab's number takes.

**A hidden toolbar button comes back while something needs you.** In v1.3.0 a hidden bottom-drawer, right-drawer or Scratch button returned while its shell was busy. It now returns while something in there is waiting on an answer too.

**OSC 9;4 progress counts as working.** A drawer or tool float running a program that reports indeterminate progress keeps its toolbar dot lit. A determinate report is a real progress bar rather than an agent turn, and does not count.

**A workspace inside a Git repo.** A workspace pointing at a package inside a monorepo is now part of the repo that encloses it. It shows its branch and what has changed, and that repo's worktrees are listed under it in the ⌘P picker. Creating a worktree from it opens the workspace's own folder inside the new checkout and copies your ticked files into that same folder. Both went to the repo root before. Your home folder is never treated as an enclosing repo.

## Changed

**Panes round with the window.** With `window-chrome` off, a pane against the window's edge takes a radius concentric with the window's own, in drawers as well as the canvas.

## Fixed

**A ⌘-hovered link only highlighted in the focused pane.** Holding ⌘ over a link in a pane that did not have focus did nothing until the pointer moved. Every visible pane now hears the modifier.

**`window-gutter = 0` ran the panes into the toolbar buttons.** The gutter insets the left, right and top edges. The space above the toolbar is its own now and no longer shrinks with the gutter.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
