The first public build of ZenTerm.

Ghostty renders the text and runs the shell. ZenTerm is the app around it: floating panes, drawers, tool floats, and workspaces, with a keyboard-first way through all of it.

This is a version 0, and the leading zero is doing work. It has been a daily driver for weeks, but chords and config keys can still change before 1.0.

## Requirements

macOS 14 or later, Apple Silicon. Signed and notarized, so it opens without a warning.

## Install

Open the DMG and drag ZenTerm to Applications.

Start with [onboarding](https://github.com/praxis-labs-io/zen-term/blob/main/docs/onboarding.md): first launch, the shortcuts worth learning first, and setting up a workspace.

Configuration is a plain text file in `~/.config/zen-term/`. Settings (⌘,) writes it for you, and you can hand-edit it. Every option is annotated in the [config reference](https://github.com/praxis-labs-io/zen-term/blob/main/docs/config/config).

## Known gaps

- No auto-update. Re-download to update.
- Apple Silicon only.

## Reporting a bug

Open an [issue](https://github.com/praxis-labs-io/zen-term/issues) with the version from the bottom of Settings (⌘,).
