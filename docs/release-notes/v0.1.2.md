A fix for a launch crash in v0.1.1.

## Fixed

v0.1.1 crashed on launch for downloaded builds. The app looked for its bundled resources at a path that only existed on the machine that built the release, so a copy that ran in testing failed to open anywhere else. v0.1.2 loads those resources from where they ship inside the app, so a downloaded build opens.

## Install

Open the DMG and drag ZenTerm to Applications. There is no auto-update yet, so re-download to update. macOS 14 or later, Apple Silicon.

## Reporting a bug

Open an [issue](https://github.com/zen-term/zen-term-releases/issues) with the version from the bottom of Settings (⌘,).
