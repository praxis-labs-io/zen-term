## Fixed

**Paste lands in the field.** ⌘V in the command palette search, a Settings field, the workspace form, or a tool float's fields used to paste into the terminal behind them. It goes into the field you're typing in now.

## Changed

**Folder fields have a Choose button.** The workspace folder and a tool float's directory each carry a Choose button on the right. It opens the native folder picker at the path already in the field, or your home folder when the field is empty, and it reaches by arrow keys and Tab like the other controls, so you can pick a folder without the mouse.

**Palette rows open on a single click.** A command in the palette and a workspace in the picker open on one click. Enter still works.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
