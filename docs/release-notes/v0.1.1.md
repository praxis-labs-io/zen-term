A maintenance release on the first public build.

## New

**Acknowledgements.** ZenTerm now ships attribution for the third-party libraries and fonts it links and embeds. Open the App menu, then About, then Acknowledgements to read the notices in a themed, scrollable window. A plain-text copy also sits at the top level of the app.

## Fixed

The app now ships only the components it declares. v0.1.0 carried an unused terminal backend bundle left over from an earlier build. v0.1.1 drops it, so the download matches what the app runs.

## Install

Open the DMG and drag ZenTerm to Applications. There is no auto-update yet, so re-download to update. macOS 14 or later, Apple Silicon.

## Reporting a bug

Open an [issue](https://github.com/zen-term/zen-term-releases/issues) with the version from the bottom of Settings (⌘,).
