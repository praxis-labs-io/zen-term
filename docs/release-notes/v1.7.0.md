## New

**SSH hosts.** Add a host in Settings → SSH Hosts, or with an `ssh-host` line in your config. A host is a `Host` alias from `~/.ssh/config` or a `user@host`. Every host appears in an SSH section of the sidebar with a dot: dim for Offline, the theme's positive color for Online, accent for Connected. ZenTerm checks each host about once a minute, and again on wake and when the network changes. It reads the host's ssh greeting and never logs in. Selecting a host opens its Connect screen, and ⏎ connects. A host that reads Offline asks "Connect anyway?" first. ⌘⌃1…9 and ⌘⌃[ ] step through workspaces and connected hosts, and pass over the rest.

**A connected host runs its panes over one ssh login.** Each pane, drawer and tab opens your login shell on the host, so a host asks for its password once. Programs there see the same `TERM_PROGRAM` and `COLORTERM` a local pane gets. When an agent on a host waits for you, the host's dot takes the waiting color. Tool floats stay on this Mac: the shortcut shows a toast saying so.

**Disconnect with ⌘⌃W.** On a connected host the close-workspace shortcut is Disconnect, in the command palette too. It does not ask. ⌘W on a Connect screen closes it and lands where closing a workspace would, and asks first only when it is the last thing in the window.

**Name a host.** Edit a host in Settings → SSH Hosts to show a name in its place, such as Production for `prod`. ssh still connects with the alias. In the config the line reads `ssh-host = prod: Production`. Click a host, or press ↩ on it, to open Edit, which also holds Remove. Removing a host asks first while it is connecting or connected.

## Changed

**Scroll areas fade at an edge with more to see.** Lists, popovers and panels fade out at an edge that has content beyond it, and the fade goes away when you reach the end.

## Fixed

**A failed save stayed out of sight.** When the Tools form could not save or delete a tool float in your config, the error appeared as a toast. It now shows inside the form, where you can retry.

**A long host name in the Couldn't Connect toast.** The name is shortened in the middle so the toast keeps its width.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
