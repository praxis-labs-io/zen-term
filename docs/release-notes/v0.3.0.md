## New

**Fill Screen (⌘⇧F).** The window grows to fill the desktop, short of macOS's own fullscreen, so it stays a window you can put back. It sits beside Focus Mode rather than taking its place.

**Check for Updates.** ZenTerm still checks on its own, but now you can ask. Open the command palette (⌘P) and run Check for Updates; it tells you when you're on the latest. It ships without a chord, so bind one if you want it on the keyboard.

**An off switch for background update checks.** Settings → General → Updates turns the automatic check off. It stays on unless you change it.

## Changed

**Zoom is now Focus Mode.** The chord is still ⌘F, and it still brings one pane or drawer up to fill the window. The name now says what it does.

**The window shows its buttons.** The standard macOS window buttons are back and on by default. Hide them from Settings → Appearance for the bare window.

**⌘W reads the context.** A focused drawer closes the drawer, the last pane closes the tab, and a pane closes the pane. A toast names what closed, so nothing goes without a word.

**Keyboard reaches all of Settings.** Arrow keys and Tab move through every control and back to the section list, so you can work Settings without the mouse.

## Fixed

**The update card shows what changed again.** The card that announces a new version was arriving with an empty list. It carries the highlights once more.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

Open an [issue](https://github.com/zen-term/zen-term-releases/issues) with the version from the bottom of Settings (⌘,).
