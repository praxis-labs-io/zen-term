## New

**Worktrees in the picker.** A repo's worktrees are listed under its workspace in the ⌘P picker, each with its folder and branch. Opening one runs the workspace's layout in that folder, in a tab named for both.

**Create a worktree.** Press ⌥⏎ over a workspace in the picker. Name a new branch and pick where it starts, or type the name of a branch that already exists to check that one out. If your main checkout is on that branch, ZenTerm asks before moving it. The card names each step while it works.

**Remove a worktree.** Press ⌥⌫ over a worktree row in the picker. Before anything is deleted, the confirm lists what goes with the folder: uncommitted files, commits no branch holds, the tabs open in it, and the files copied into it. The branch and its commits stay.

**Copy what a worktree needs to run.** A new worktree gets what git tracks and nothing it ignores, so it has no `.env` and no `node_modules`. The workspace form has a "Copy into new worktrees" list of what git ignores in the folder: tick what to bring across. In the workspaces file it is a repeatable `carry` field. On APFS a copied `node_modules` costs close to no space.

**Branch and changes in the picker.** Each workspace and worktree row shows its branch, with counts for staged, modified, renamed, deleted, untracked and conflicted files, and commits ahead or behind.

## Changed

**A hidden drawer or scratch button comes back while its shell is busy.** If you hid it with `hide-toolbar-buttons`, it now shows in the footer while that shell runs something out of sight, so work you cannot see still has a handle.

**More icons for tool floats.** The icon picker has more symbols to choose from, split into Symbols and Brand marks. A float already using an icon keeps it.

## Fixed

**Ctrl-h/j/k/l stopped moving between panes after nvim crashed.** A pane kept its nvim flag when nvim died without a clean exit, so the navigation chords went to whatever ran there next. The flag now clears the moment nvim goes away, however it exits. Update zen-navigator.nvim to get this; an older copy of the plugin works as before.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
