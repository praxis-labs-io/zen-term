## New

**Zen Ink.** ZenTerm now ships its own theme: blue-black ink with a cobalt accent. It is the default when `theme` is unset. Rosé Pine Zen is still bundled: set `theme = rose-pine-zen` in your config, or pick it in Settings → Appearance → Theme. With [zen-theme.nvim](https://github.com/praxis-labs-io/zen-theme.nvim), Neovim takes the matching `zen-ink` colorscheme.

**Rename a workspace.** Right-click a workspace in the sidebar, or run Rename Workspace from the palette. The name lasts until you quit. In ⌘P, New Workspace takes what you typed as the new workspace's name. From a shell, `zen workspace rename` does the same, and `zen workspace new --title` names a new one.

**Drag to resize panes.** Drag the gap between two panes to move the split.

**Agent asks show at once.** ZenTerm now reads the status Claude Code reports about itself. A permission ask turns its tab and its agent row to waiting the moment it happens, without waiting for the screen to change. Other agents, and Claude Code under tmux, keep working as before.

## Changed

**A refreshed look.** Tabs are pills with a close button on hover, the same style in the tab bar and the workspace strip, and they no longer show a number. Cards, menus, popovers, fields and buttons share one set of styles, and floating cards stand off the window behind them with a raised fill.

**One dot, one meaning.** A colored dot is about what runs there: red when an agent waits for you, blue when it finished its turn, the accent while something runs. Remote hosts show their status as plain text.

**Agent rows show what the agent is doing.** A row's title is the agent's own title or its current task, never a state word.

**The cursor takes the accent color.** It matches the focused pane's border on every theme and follows `accent-color`. A theme's `cursor-color` no longer applies.

**The focus border shows only when it is needed.** A pane shows its focus border only while another pane, a drawer or a tool shares the screen.

**In-app notices are off by default.** A tab, drawer or tool that needs you, or a long command that finished, no longer raises a card on its own. The tab's dot stays, and an agent that needs you still posts a macOS banner while ZenTerm is in the background. To get the cards back, set Settings → General → "Notice for a tab that needs you" to Sticky or Auto, or set `attention-toast` and `completion-toast` in your config.

**"SSH" is now "Remote hosts"** in the sidebar and in Settings.

**⌘Return submits any form.** Every form card takes the same shortcut.

## Fixed

**Esc no longer leaves full screen.** Closing a card with Esc from a text field keeps the window in full screen.

**Git and SSH lookups no longer hang** while the app is under heavy load.

**New Workspace works from a window with no tab.**

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
