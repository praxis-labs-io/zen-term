## New

**The `zen` CLI.** `zen` ships inside ZenTerm and is already on your PATH in every pane on this Mac. It lists the open windows, workspaces, tabs and panes. It opens workspaces, tabs and panes, sends text to a pane and reads what the pane printed, creates and removes worktrees, and runs any action you can bind to a shortcut. Run `zen --help` for the commands, or read the [zen CLI Guide](https://zenterm.io/docs/cli) to get started.

**Nothing moves unless you ask.** A tab or pane that `zen` opens starts behind the one you are looking at, so an agent can start a dev server and read its output while you keep working. Add `--focus` to switch to it.

**Closing running work takes `--force`.** `zen` refuses to close a tab, pane or workspace with something still running, or to remove a worktree with uncommitted files, and lists what would stop. Pass `--force` to go ahead.

**SSH hosts.** On a connected host, `zen` opens tabs and sends to and reads its panes, with the host addressed as `ssh:<alias>`. Run it from a pane on this Mac.

**Use it outside ZenTerm.** To run `zen` from another terminal or a script, link it onto your PATH:

```sh
sudo mkdir -p /usr/local/bin
sudo ln -s /Applications/ZenTerm.app/Contents/MacOS/zen /usr/local/bin/zen
```

## Changed

**A pane started from a command shows that command as its title.** A workspace's `main`, `right` or `bottom` command, or one started with `zen`, titles its pane until the program sets a title of its own.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
