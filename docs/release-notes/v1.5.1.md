## New

**⌘⇧A jumps to a waiting agent.** It takes you to the agent in this window that has waited longest, and each press after that steps to the next one, wrapping. It is also in the command palette as Jump to Waiting Agent, and rebinds as `next_waiting_agent`.

**Agents waiting in other windows.** The Agents section carries a row counting agents that wait in your other windows. Click it or press Return and ZenTerm raises that window and lands on the one that has waited longest. An agent asking in a window you were not in used to go unannounced. Its own window now colors the tab and posts the card as well.

**Name the agent programs you use.** The new `agents` key, and the Agents group in Settings under General, lists the programs ZenTerm treats as agents beside the built-in claude and codex, separated by commas or spaces. The program your `ai` key runs counts too, so an existing config keeps working. A listed program counts when a workspace pane or tool float starts it, or when a notification's title names it.

**An agent's full message on hover.** Point at a row in the Agents section to read the whole of what its agent last said, not only the first line.

**Worktrees removed outside ZenTerm.** A worktree deleted from a shell or another tool stays open, marked removed in the sidebar and the picker. A card says so once and offers Close Workspace, and ⌘⇧⌫ on its picker row does the same. It never closes on its own, since an agent in it may still be running. A pane, drawer or float you open meanwhile starts in the parent workspace's folder. Removing an open worktree from the picker now shows its progress on the row and drops the row when it is done.

## Changed

**Claude and Codex are read from their own signals.** ZenTerm reads Codex's state from its terminal title, so Codex shows working, waiting and done like Claude does. A Claude or Codex you start by hand at a prompt is listed as soon as its title appears. A waiting Claude or Codex clears when the agent moves on, rather than on the first key you press. Other agents clear when you type to them.

**Looking at a waiting agent no longer answers it.** An agent that asks while you are watching its pane still reads waiting in the sidebar until you answer, and leaving the app and coming back no longer clears it. Its tab number and card still clear once you have seen them.

**A done row fades once you have seen it.** After five seconds focused on an agent's pane, its Done row goes quiet. Leaving the pane restarts the clock. A failed exit stays until you answer it.

**Only an agent's notification asks for you.** A notification from a program that is not an agent now lands as a finished card with its own words, and no macOS banner. If a program you rely on stopped raising a banner, add it to `agents`.

**A card in a background window waits for you.** A card that clears itself starts counting down once you are in its window, and stops if you leave, so it is never gone before you see it.

## Fixed

**An agent that exited right away stayed in the Agents list.** An agent a workspace launched now reports its own exit, even one that quits within its first second.

**The longest wait is dated from its question.** A command finishing earlier in the same pane no longer moves an agent's wait up the list, or sends ⌘⇧A to the wrong pane.

**A command finishing in another window said nothing.** A long command that ends in the visible tab of a window you are not in now posts its card.

**Focus showed where the keyboard was not.** A pane, drawer or tool float kept its halo and a live cursor when its window lost key, or when the sidebar took the keyboard, and a tool float kept its cursor live under scroll and search mode. Each one now shows focus only while it has the keyboard.

**The cursor stopped blinking after a float or drawer closed.** It blinks again when focus returns to the pane.

**Typing went under an open float.** When a pane behind an open float exited, the keyboard moved to the pane that was left. It stays with the float now.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
