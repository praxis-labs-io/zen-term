Corrections to the copy, and a ZenTerm installer window.

## Fixed

**The drawer resize shortcut.** Settings and the config reference both named an Option-arrow for resizing a drawer. The chord is ⌘⇧HJKL, and it always was. The copy now names the one that works.

## Changed

**The installer.** Opening the DMG shows a ZenTerm window with the app and an Applications folder, in place of the macOS default.

**One word per concept.** The Settings section named "Keybinds" is now "Shortcuts", and the menu bar reads ZenTerm rather than zen-term. Same throughout the config docs.

**Licenses and config docs ship with the release.** THIRD-PARTY-NOTICES.md and the config reference now publish on every release, so what you read describes the version you have.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

Open an [issue](https://github.com/zen-term/zen-term-releases/issues) with the version from the bottom of Settings (⌘,).
