## New

**A tab's directory on hover.** Point at a tab to see the directory of its focused pane, with your home folder shortened to `~`. It replaces the "Focus tab" tooltip.

## Changed

**Three states for an agent.** An agent in the Agents section is working, waiting on you, or idle. The Done and Exited rows are gone.

**A turn you missed waits for you.** When an agent finishes a turn in a tab, drawer or tool float you are not looking at, it waits: its tab number takes the attention color, its row moves to the top of Agents, ⌘⇧A reaches it, and a notice says it finished its turn. Looking at it or starting a new turn clears it. A turn that ends while you watch stays quiet. Coming back to the window clears every finished turn that is on screen.

**Finished turns use the waiting notice.** An agent's turn ending now follows `attention-toast`, not `completion-toast`. If you set `completion-toast = auto` so these would clear themselves, set `attention-toast` as well.

**A crashed agent waits for you.** An agent that exits with an error now waits until you answer it, rather than showing Exited. Stopping it with Ctrl-C is not a crash.

**Claude's idle banner only comes when it matters.** Claude's "waiting for your input" banner appears only over a turn you have not seen yet.

**Notices.** Settings and the config reference call ZenTerm's in-app alerts notices, and keep "notification" for macOS banners.

## Install

ZenTerm updates itself. On v0.2.0 or later, the update card appears in the app. For a first install, open the DMG and drag ZenTerm to Applications. macOS 14 or later, Apple Silicon.

## Reporting a bug

From inside the app: Help → Report an Issue prefills the version and your environment. You can still open an [issue](https://github.com/praxis-labs-io/zen-term/issues) directly.
